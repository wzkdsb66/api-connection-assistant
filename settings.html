API 连接助手

这个插件是干嘛的？

把「连接一个 AI 站点」想成寄快递：网址是收件地址，密钥是证明你有权寄件的签名，模型是你选哪条线路。以前每换一个站点都要手动填这三样，填错一项消息就发不出去。这个插件把三样打包成一个「站点」存好，以后点一下「使用」整体换好——只换连接，不碰你的角色卡、预设和提示词。

三步上手
  1. 第 1 步：新增一个站点

    点「新增站点」，填三样：名称（随便起，比如「白天主力」）、API 网址（形如 https://xxx/v1）、API Key（默认打码，点「显示」可核对）。填完点「保存站点」。密钥存进酒馆自带的保险库，插件只记住用的是哪一把。

  2. 第 2 步：把模型加进来

    点站点卡片上的「模型」弹出挑选面板：顶部搜索框过滤，勾选想要的，点「添加所选」；面板不用关，可以继续搜继续加。也可以编辑站点时手写模型 ID，多个用逗号分隔。

  3. 第 3 步：一键切换

    点「使用」，插件会替你执行四条酒馆官方命令换好连接，提示「已切换到…」就成功了。想换模型直接点模型行。右上角⚡球（悬浮快切窗）可以随手切换，球和窗按住都能拖动。

悬浮快切窗

设置里勾选「启用悬浮快切窗」出现⚡球：点球开关面板，点站点名切换，点「模」展开模型列表。位置自动记住。

魔术棒快切（手机友好）

聊天输入框旁的魔术棒（✨）菜单里有「API 快切」，点开是一个不挡屏幕的紧凑面板：点站点名直接切换，点「模」挑模型，切换成功自动收起。手机上不用去够⚡球。

一个站点多把密钥

密钥栏可以填多把，用逗号分隔，第一个是默认。点卡片上的钥匙按钮在多把之间轮换，适合一把额度用完换下一把。

分组和排序

站点多了可以分组归类，顶部分组按钮一键筛选；卡片右侧 ↑↓ 按钮自己排顺序，刷新、重启都不乱。

使用统计

每次切换并生成成功，给当前站点记一次「用过 n 次」。只记在本机、不参与排序，想清零点「重置使用统计」。

备份与搬家（导入 / 导出）

「导出」把站点存成 JSON 文件，默认不含密钥；换电脑或重装后用「导入」按「名称 + 网址」合并恢复。勾了「包含密钥」导出会弹二次确认，文件名带 INCLUDES-KEYS 前缀——这个文件要当密码保管。

界面语言

设置里可选「跟随酒馆 / 中文 / English」，点一下立即生效。
