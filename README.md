# API 连接助手（SillyTavern 扩展）

管理一套属于自己的 API 配置（名称 + 地址 + 密钥 + 模型），一键切换、一键拉取站点模型列表。切换时只修改 API 连接，不改动补全预设。

## 版本要求

- SillyTavern `1.18.0` 或更高
- 密钥会写入酒馆原生密钥库（`api_key_custom` 命名槽位）；扩展数据同样保存在你本机的酒馆目录里
- 本插件不联网上报数据、不导出密钥、密钥不随角色卡走

## 安装（推荐：酒馆内一键安装）

在酒馆「扩展 → Manage Extensions → Install extension」里填入：

```text
https://github.com/wzkdsb66/api-connection-assistant
```

## 安装（手动复制）

把整个 `api-connection-assistant` 文件夹复制到你的酒馆扩展目录，二选一：

- 用户作用域：`data/<你的用户名>/extensions/api-connection-assistant/`
- 全局作用域：`public/scripts/extensions/third-party/api-connection-assistant/`

然后重启酒馆（或刷新浏览器），在「扩展」面板中确认 `API 连接助手` 已启用。

## 使用

1. 打开「扩展 → API 连接助手」，点「新增 API 配置」：填名称、API 地址、密钥，保存。
2. 点「拉模型」：扩展会请求 `<API地址>/models`，成功后模型列表会变成可点击按钮。
3. 三种切换入口：
   - **扩展设置面板**：每个配置一行，点「应用」切换。
   - **悬浮快切窗**：勾选开关后出现 ⚉ 悬浮球；窗口可以按住标题栏拖动，位置自动记忆。
   - **API 面板入口**：酒馆 API 连接抽屉里会出现「API 连接助手」块，下拉选择 + 应用。
4. 悬浮窗里点「模」展开模型按钮，点任意模型 = 填入该模型并立刻切换。

## 切换时到底改了什么

按顺序执行四步（全部是酒馆官方命令）：

1. `/api custom` —— 切到 Chat Completion 的 Custom (OpenAI-compatible)
2. `/secret-id` —— 激活这个配置对应的命名密钥
3. `/api-url` —— 填入 API 地址并重新连接
4. `/model` —— 填入模型名

**不会**改动：补全预设（preset）、系统提示、上下文模板、正则、世界书等任何生成设置。

## 验收清单

- [ ] 扩展面板能新增/编辑/删除 API 配置
- [ ] 点「应用」后：主 API 变为 Custom (OpenAI-compatible)，地址/密钥/模型正确填入，补全预设保持不变
- [ ] 点「拉模型」能返回模型列表；点模型按钮能切换模型
- [ ] 悬浮窗可按住标题栏拖动，刷新页面后位置保持
- [ ] API 面板入口能下拉选择并应用
- [ ] 删除配置后，酒馆密钥库里对应的命名密钥同步删除
- [ ] 禁用扩展后，悬浮球、悬浮窗、API 面板入口、扩展设置块都消失

## 边界说明

- 拉模型列表是浏览器直接请求站点，个别站点若禁止跨域（CORS）会失败；这时可以手动填模型名，切换功能不受影响。
- 「拉模型」成功即代表地址+密钥可用；失败原因会显示在测试徽标上。
- 本版本面向 OpenAI 兼容端点（`/v1` 风格）；Claude/Gemini 等官方接口不在支持范围。
